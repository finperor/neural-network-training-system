# 神经网络训练系统

## 项目简介

基于 PyTorch + PyQt6 的化工过程数据神经网络训练工具，提供从数据导入、预处理、模型配置、训练到结果分析的全流程 GUI 操作界面，可替代 MATLAB 进行化工过程数据的神经网络建模。

## 环境要求

- Python 3.8+
- Windows 10/11（支持 Linux/macOS）
- NVIDIA 显卡（可选，用于 GPU 加速训练）

## 安装步骤

### 1. 安装 Python 依赖

```bash
pip install torch pandas numpy PyQt6 matplotlib scikit-learn
```

如无 NVIDIA 显卡或 CUDA，可安装 CPU 版本：
```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

### 2. 运行程序

```bash
python main.py
```

## 功能说明

### 1. 数据导入
- 支持 CSV 格式的过程数据
- 自动识别列名和数据类型
- 提供数据预览（前 20 行表格展示）
- 统计信息：均值、标准差、最小/最大值、缺失值数量与占比

### 2. 数据预处理
- **自动数据质量分析**：检测各列的缺失率、自动推荐处理方法，标记是否存在异常值
- **缺失值处理**：支持均值、中位数、前向填充、后向填充、线性插值、KNN 填充及自动选择
- **异常值处理**：
  - 检测方法：IQR（四分位距法）和 Z-Score（标准差法），阈值可调
  - 处理方式：删除异常值所在行或裁剪到合理范围
- **数据归一化**：Min-Max 归一化（范围可调）和 Z-Score 标准化，支持不归一化

### 3. 模型配置
- **任务类型**：回归 / 分类
- **神经网络类型**（5 种）：
  | 模型 | 适用场景 |
  |------|---------|
  | MLP（全连接）| 普通表格数据的回归与分类 |
  | RNN（循环神经网络）| 时序数据的短期依赖建模 |
  | LSTM（长短期记忆）| 较长时序依赖，化工过程推荐首选 |
  | GRU（门控循环单元）| LSTM 的轻量替代，参数更少训练更快 |
  | CNN-1D（一维卷积）| 局部时序模式提取（如传感器信号）|
- **网络结构**：根据模型类型动态切换配置界面（无重影）
  - MLP：可自定义隐藏层数和每层节点数，动态添加/移除
  - RNN/LSTM/GRU：隐藏单元数、层数、是否双向
  - CNN-1D：两通道卷积、卷积核大小
- **训练超参数**：
  - 优化器：Adam / SGD / RMSprop / AdamW
  - 学习率（0.00001 ~ 0.1）
  - 批次大小（4 ~ 512）
  - 训练轮次（1 ~ 1000）
  - 损失函数：MSE / MAE / Huber
  - 学习率调度：阶梯衰减 / 指数衰减 / 余弦退火 / ReduceLROnPlateau
  - 正则化：L2 正则化（可调系数）
  - Dropout（0 ~ 0.9）
  - 早停耐心（1 ~ 50 轮）
- **模型结构预览**：确认前可弹窗查看完整的网络结构与参数

### 4. 模型训练
- **硬件选择**：自动检测 GPU（显示名称与显存），可切换 CPU/GPU
- **数据集划分**：训练集/验证集/测试集比例可调（默认 70/15/15）
- **时序模型参数**：序列长度设置、时序划分开关
- **实时监控**：
  - 黑色背景的损失曲线图（绿色=训练损失，红色=验证损失）
  - 当前轮次/总轮次、训练损失、验证损失、学习率实时显示
  - 进度条显示训练进度百分比
- **训练控制**：开始 / 暂停 / 继续 / 停止
- **早停机制**：验证损失连续 N 轮不下降自动停止
- **最佳模型保存**：训练过程中自动追踪验证损失最低的模型状态，训练结束后恢复用于评估

### 5. 结果分析
- **评估指标**：
  - 回归：MSE（均方误差）、RMSE（均方根误差）、MAE（平均绝对误差）、R²（决定系数）、MAPE（平均绝对百分比误差）
  - 分类：Accuracy（准确率）、Precision（精确率）、Recall（召回率）、F1
- **可视化图表**（使用 QPainter 绘制）：
  - 预测对比曲线：绿色真实值 vs 红色预测值
  - 真实值 vs 预测值散点图：含 y=x 完美预测参考线
- **模型导出**：
  - 导出模型 (.pt/.pth)：含 model_state_dict + 配置 + 指标
  - 导出完整项目：model.pth + metrics.txt + config.json
- **评估指标保存**：可单独导出为文本文件

## 工作流程

```
数据导入 ──→ 数据预处理 ──→ 模型配置 ──→ 模型训练 ──→ 结果分析
   │              │              │              │              │
 CSV加载      缺失值处理     目标变量选择    设备选择      评估指标
 数据预览     异常值处理     模型类型选择    数据划分      可视化图表
 数据统计     数据归一化     网络结构配置    实时监控      模型导出
                            训练参数设置    暂停/继续
```

各阶段通过 PyQt 信号链式传递数据，无需手动导出中间文件。

## 数据格式说明

CSV 文件第一行为列名（变量名称），后续每行为一个时间点的数据。例如：

```csv
温度,压力,流量,产品质量
85.2,1.2,100.5,92.5
86.1,1.25,101.2,93.2
...
```


## 注意事项

- 目标变量（要预测的列）需在模型配置阶段的列表框中勾选
- 时序数据建议使用 LSTM 或 GRU 模型
- 数据量较小时建议使用较小的网络结构以防止过拟合
- 训练损失应逐渐下降，验证损失若持续上升则说明过拟合
- R² 越接近 1 模型拟合越好，负值说明模型效果差于简单均值预测
