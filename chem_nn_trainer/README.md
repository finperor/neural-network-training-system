# 化工过程神经网络训练系统

## 环境要求

- Python 3.8+
- Windows 10/11
- NVIDIA显卡（可选，用于GPU加速）

## 安装步骤

### 1. 安装Python依赖

```bash
pip install torch pandas numpy PyQt6 matplotlib scikit-learn
```

如无NVIDIA显卡或CUDA，可安装CPU版本：
```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

### 2. 运行程序

```bash
python main.py
```

## 功能说明

### 数据导入
- 支持CSV格式的过程数据
- 自动识别列名和数据类型
- 提供数据预览和统计功能

### 数据预处理
- **缺失值处理**: 支持均值、中位数、前向填充、插值、KNN填充等多种方法，可自动选择
- **异常值处理**: 支持IQR和Z-Score检测方法，支持删除或裁剪处理
- **数据归一化**: 支持Min-Max归一化和Z-Score标准化

### 模型配置
- **模型类型**: MLP、RNN、LSTM、GRU、CNN-1D
- **网络结构**: 可自定义隐藏层数量和每层节点数
- **训练参数**: 优化器、学习率、批次大小、轮次等均可配置

### 模型训练
- 支持CPU和GPU训练
- 实时显示训练损失曲线
- 支持早停机制
- 可暂停和恢复训练

### 结果分析
- 评估指标：MSE、RMSE、MAE、R²等
- 可视化：预测曲线、真实值vs预测值散点图
- 模型导出：支持导出为.pt格式

## 数据格式说明

CSV文件第一行为列名（变量名称），后续每行为一个时间点的数据。例如：

```csv
温度,压力,流量,产品质量
85.2,1.2,100.5,92.5
86.1,1.25,101.2,93.2
...
```

## 注意事项

- 目标变量（要预测的列）需要在模型配置阶段选择
- 时序数据建议使用LSTM或GRU模型
- 数据量较小时建议使用较小的网络结构以防止过拟合
